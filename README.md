# 手势粒子 · Gesture Particles

> 用摄像头识别手部姿态，实时驱动 3D 粒子形态——张开手掌粒子扩散、握拳收缩、单指摇摆旋转。
> 单文件网页，无需构建，无需安装依赖，打开即用。

**🔗 在线演示：<https://zqwd023.github.io/gesture-particles/>**

> 在线演示走 HTTPS，摄像头权限可正常申请；如果不想开摄像头，鼠标拖拽同样可以玩。

---

## 一、它是什么

一个跑在浏览器里的实时粒子系统。粒子按 7 种预设形态分布，手在摄像头前的动作会被映射成粒子系统的控制参数：

- 手部**张合** → 粒子扩散 / 收缩
- 手部**左右摇摆** → 粒子群旋转
- 手部**前后移动** → 视角缩放

手部关键点检测用 MediaPipe `HandLandmarker`（21 个关键点），渲染用 Three.js 的 `Points` + 自定义 Shader。

## 二、交互方式

| 操作 | 效果 |
|---|---|
| 鼠标拖拽 | 旋转（无摄像头时的降级操作） |
| 滚轮 | 缩放 |
| **张开手掌** | 粒子放大扩散 |
| **握拳** | 粒子收缩 |
| **单指左右摇摆** | 粒子旋转 |
| **单指前后移动** | 拉近 / 推远 |
| 按 `F` 或点右上角按钮 | 全屏 |

右侧控制面板可切换形态、改粒子颜色（含「恢复原配色」）、调**粒子大小**和**扩散强度**。

## 三、7 种形态模型

`爱心` · `花朵` · `土星` · `烟花` · `地球` · `昙花` · `千里江山`

每个形态是独立的粒子位置生成函数，切换时粒子平滑过渡（不是直接跳变）。

## 四、技术实现

| 项 | 说明 |
|---|---|
| 渲染 | Three.js 0.160（`Points` + 自定义着色器，GPU 端逐粒子计算） |
| 手部识别 | MediaPipe `@mediapipe/tasks-vision@0.10.14` 的 `HandLandmarker`（float16 模型） |
| 摄像头 | `navigator.mediaDevices.getUserMedia`，本地预览 + 关键点叠加层 |
| 依赖加载 | 全部走 `import()` 动态导入，**配了 4 个 CDN 备用**，一个挂了自动换下一个 |
| 工程形态 | 单个 HTML 文件（1115 行），CSS/JS 内联，无打包、无 npm 依赖 |

CDN 降级顺序：`jsdelivr` → `unpkg` → `esm.sh` → `skypack`，全部失败才会报错。

## 五、本地运行

**方式一：直接双击 `gesture-particles.html`**
可以看渲染和鼠标交互，但**摄像头会失败**——浏览器只在 `https` 或 `localhost` 下才允许 `getUserMedia`，`file://` 不属于安全上下文。

**方式二：起一个本地服务器（推荐，摄像头可用）**

```bash
# 任选一种
python -m http.server 8000
npx serve .
```

然后打开 <http://localhost:8000/gesture-particles.html>。

**方式三：直接用在线演示**
<https://zqwd023.github.io/gesture-particles/>

浏览器要求：Chrome / Edge / Safari 较新版本，需支持 WebGL2 与 `getUserMedia`。

## 六、目录结构

```
.
├── index.html                      # Pages 入口，自动跳转到演示页
├── gesture-particles.html          # ★ 手势粒子主程序（单文件网页）
│
├── 摄像头检测.ps1                  # 摄像头排查：抓一帧判断是否全黑，存预览图
├── 双击运行检测.bat                # 上面脚本的快捷入口
├── 摄像头预览.png                  # 检测脚本的输出示例
├── 重置摄像头_管理员.ps1           # 摄像头驱动彻底重置（需管理员权限）
├── 重置摄像头_管理员.bat           # 上面脚本的快捷入口
│
├── 论文深度解析_NIPT调度与QUBO.md   # NIPT 检测日期与批次联合优化论文的方法逐条解析
├── build_docx.py                   # 把上述解析构建成排版好的 Word 文档（python-docx）

```

> 说明：这个仓库里其实装了两类互不相关的内容。前两项是**手势粒子可视化项目**；`论文深度解析…` + `build_docx.py` + `figs/` 是另一份**论文方法解析与 Word 排版工具**，因同处一个工作目录而一起归档。如果只想看网页项目，关注 `gesture-particles.html` 即可。

## 七、附带的摄像头排查工具（Windows）

调试手势识别时最容易踩的坑是「设备管理器里摄像头一切正常，但画面全黑」。这两个脚本就是为定位这类问题写的：

| 脚本 | 作用 |
|---|---|
| `双击运行检测.bat` | 直接向摄像头取一帧，判断是否真的全黑，并把这一帧存成 `摄像头预览.png` |
| `重置摄像头_管理员.bat` | 把摄像头设备断电重新枚举 + 重启 Windows 相机服务，修复驱动/固件卡死（需管理员） |

只在 Windows 上有效，用的是 WinRT 的 `MediaCapture` API。

## 八、关于论文解析与 Word 构建

`build_docx.py` 用 `python-docx` 把 `论文深度解析_NIPT调度与QUBO.md` 排成中文学术格式的 Word 文档（正文宋体、标题黑体、图表编号与题注、页边距等）。

```bash
pip install python-docx
python build_docx.py
```

需要 `figs/` 里的配图与脚本同目录。

## 九、素材说明

演示中的粒子形态由代码程序化生成，不含第三方美术素材。手部识别模型来自 Google MediaPipe 官方公开模型。
